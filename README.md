# Antonietta Pascarella — UI/UX Portfolio

Static GitHub Pages portfolio with a local GLB avatar rendered through Three.js.

## Publish on GitHub Pages

1. Create a repository (for example `portfolio`).
2. Upload `index.html`, the `assets/` folder and this README.
3. In **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/root`.
4. Open the GitHub Pages URL.

The site uses Google Fonts and Three.js/GLTFLoader from jsDelivr, so the browser needs internet access for those external resources. The avatar itself is local in `assets/avatar.glb`.
